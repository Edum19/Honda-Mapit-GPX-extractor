MapitGPX

Descarga todas tus rutas de Honda Mapit en archivos GPX. Todo ocurre en tu navegador.

01Qué se envía y adónde

DatoDestino¿Se guarda?
Correo y contraseña Directamente a Amazon Cognito, el servicio de acceso de Mapit. No pasan por esta web. No. El campo se vacía al enviarlo.
Claves temporales y rutas A la API de Mapit desde tu navegador. Si Mapit lo bloquea, las peticiones pasan por una función de esta web que solo las reenvía. No. Las claves caducan en aproximadamente una hora.
Archivos GPX Solo existen en la memoria de esta pestaña hasta que los descargas. No. Sin cuentas, cookies, analítica ni almacenamiento local.

Esta herramienta no es oficial ni tiene relación con Honda ni con Mapit. Usa tu propia cuenta.

02Conectar con Mapit

Ajustes avanzados

Son los identificadores públicos que usa la web oficial de Mapit para iniciar sesión y consultar la API. No son secretos ni contraseñas. La herramienta los detecta sola en app.mapit.me; solo tendrás que rellenarlos si Mapit cambia su web y la detección falla.

  • User pool id: el directorio de usuarios donde está tu cuenta (Amazon Cognito).
  • Client id: el identificador de la app de Mapit ante ese directorio.
  • Identity pool id: intercambia tu sesión por claves temporales de acceso.
  • URL core: API de la cuenta y las motos.
  • URL geo: API de las rutas.
